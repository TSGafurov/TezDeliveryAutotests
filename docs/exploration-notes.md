# Tez Delivery — заметки по исследованию приложения

Приложение курьера: `uz.agrobank.chakana_delivery` 1.0.9, activity `.MainActivity`.
Flutter, как и TezChakana: локаторы — `content-desc` (accessibility id), `resource-id` нет.
Аккаунт: тот же реальный номер, что и в TezChakana; OTP статический `081020`.
Курьер «Тимур», ID `01-m533mc`, рейтинг 4.6, живой продовый бэкенд.

Исследовано 2026-10-02 на эмуляторе (1080x2400).

## Карта экранов

### Первый запуск
1. Шторка «Tilni tanlang»: `O'zbekcha` / `Ўзбекча` / `Ruscha` + «Tasdiqlash».
2. Вход: селектор языка (вверху слева), `+998`, EditText номера (маска `XX XXX XX XX`),
   кнопка «Davom ettirish».
3. OTP: «Tasdiqlash kodi <номер> raqamiga yuborildi», одно EditText на 6 ячеек,
   таймер «Kod N soniyadan so‘ng yana yuboriladi...» → потом «Qayta yuborish»,
   кнопка «Tasdiqlash», стрелка назад.
4. Системные разрешения: уведомления (Allow), затем свой экран
   «Joylashuvga doimiy ruxsat bering» («Har doim ruxsat berish» / «Ruxsat bermang»)
   → системный диалог геолокации (While using the app / Only this time / Don’t allow).

### Главный — «Buyurtmalar»
- Шапка: колокольчик с бейджем (`9+`) → Xabarnomalar; аватар → Profil.
- Поиск «ID orqali qidirish» (EditText), при вводе справа появляется «Tozalash»/«Очистить».
- Табы: «Faol buyurtmalar» / «Buyurtmalar tarixi» (content-desc вида
  `Faol buyurtmalar\n2 varaqdan 1`).
- Пусто: «Hech qanday natija topilmadi / Hozircha qidiruv natijalari yo‘q».
- История: карточки сгруппированы по дате, content-desc
  `30 - сентябрь\nTEZ00913\n2 000 so'm\nYetkazildi` (дата только у первой в группе).
  Листается до TEZ00011 (13 августа).

### Детали заказа (из истории)
- Заголовок `TEZxxxxx`, назад, табы «Buyurtmalar» (товары) / «Buyurtma haqida».
- Товары: `Suv Hydrolife gazsiz 330 ml\n(dona)\n2 000 so'm\n1x`.
- О заказе: Qabul qiluvchi (имя, телефон — кликабелен, вероятно звонок: НЕ тапать),
  адрес, To‘lov (Naqd), To‘lov summasi.

### Xabarnomalar
- Список «Yangi buyurtma» + дата/время; справа сверху «прочитать все» (мутирующее — не тапать
  в safe-тестах).

### Profil
- Имя, телефон, рейтинг, «Yetkazib beruvchi ID raqami» (иконка авто — декоративная).
- «Mening hamyonim» → «Hamyon»: баланс, «To‘lovlar tarixi» (`TEZ00913\nNaqd\nPepsi Market\n+ 12 000\n30.09.2026, 03:33`).
- Switch «Men tarmoqdaman» (на линии) — сейчас ВКЛ. Мутирующее, влияет на назначение
  реальных заказов — не трогать без согласования.
- «Yordam»: Koll-markaz / Elektron pochta / Telegram orqali bog‘lanish (уводят во внешние
  приложения).
- «Til»: та же шторка выбора языка (RU: «Профиль», «Мой кошелек», «Я в сети», «Выйти»…).
- «Foydalanish shartlari»: текст условий.
- «Versiya: 1.0.9», «Chiqish» → диалог «Bekor qilish» / «Tasdiqlash» (+ крестик).

## Не исследовано
- **Флоу активного заказа** (принять → забрать → доставить, отказ и т.д.) — активных
  заказов на момент осмотра нет. Это ядро приложения; нужен способ получать тестовый заказ.
- Невалидный номер / неверный OTP (не гонял, чтобы не рисковать блокировкой номера).

## Наблюдения / кандидаты в баги (проверить с владельцем)
1. Поиск по ID в истории только подсвечивает совпадение, но не фильтрует список
   (на `00871` остаётся и TEZ00913; на `99999` показывается вся история).
2. Дата-разделители в истории всегда по-русски и грамматически неверно: «30 - сентябрь»
   (и в узбекском интерфейсе).
3. «To‘lovlar tarixi» в кошельке не отсортирована по времени: TEZ00789 (28.09 09:14) выше
   TEZ00798 (28.09 10:57), а TEZ00746 (06:28) ниже обоих.
4. «Foydalanish shartlari» — текст для клиентского приложения «Tez Chakana», а не для
   курьерского.
5. Тестируемость: кнопки «Davom ettirish»/«Tasdiqlash» на экранах входа не отдельные
   узлы — слиты с полноэкранным контейнером; кнопка «Tasdiqlash» на OTP смещается при
   скрытии клавиатуры. Тапать по координатам нельзя — нужны относительные/якорные локаторы.

## Особенности автоматизации
- `adb input keyevent DEL` не стирает текст, если поле потеряло фокус — сначала тап по полю.
- Системный Back на главном экране закрывает приложение.

| ORD-01..07 | `OrdersTest`: главный экран, таб активных, карточки истории, товары и инфо заказа (сумма = карточке), Back из деталей, поиск по номеру | safe |

| PROF-01..09 | `ProfileTest`: данные курьера, меню + switch (без переключения), версия = установленной, кошелёк, помощь, условия, шторка языка (закрытие крестиком), диалог выхода (закрытие крестиком), Back с разделов | safe |
| BUG-01..03 | `KnownBugsTest`: поиск не фильтрует, кириллическая дата, сортировка выплат | known-bug (`testng-known-bugs.xml`, падают до исправления) |
